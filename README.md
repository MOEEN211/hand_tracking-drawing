# Hand Draw Studio 🎨

A modern web application that allows you to draw on a digital canvas using real-time hand tracking through your webcam.

## ✨ Features

- **Real-time Hand Tracking**: Powered by MediaPipe Hands.
- **Gesture Controls**:
  - **Pinch**: Draw or paint on the canvas.
  - **Open Palm**: Pause tracking and drawing.
  - **Two Fingers**: Quick eraser mode.
  - **Three Fingers**: Toggle quick color palette.
  - **Four Fingers**: Clear canvas confirmation.
- **Professional Drawing Tools**:
  - Pencil, Brush, Marker, Highlighter, Eraser.
  - Shape Tools: Circle, Rectangle, Line.
- **Advanced UI**:
  - Glassmorphism design with Dark/Light mode support.
  - Draggable webcam preview window.
  - Multiple drawing layers.
  - Fullscreen mode.
- **Export Options**: Save your masterpieces as PNG or PDF.

## 🚀 Tech Stack

- **Framework**: React 19 + TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS v4 + Framer Motion
- **Hand Tracking**: MediaPipe Hands
- **Icons**: Lucide React
- **Export**: jsPDF

## 🛠️ Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/MOEEN211/hand_tracking-drawing.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open your browser and allow camera access.
